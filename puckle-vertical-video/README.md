Composición animada en Remotion, sincronizada con una narración AAC. El vídeo presenta el diseño en su contexto histórico y educativo; la ilustración y la animación son conceptuales, no reconstrucciones exactas ni planos de fabricación.

## Vista previa

![Ilustración esquemática de la Defence Gun de James Puckle](public/defenseGun.svg)

## Empezar

Desde esta carpeta, instala las dependencias e inicia Remotion Studio:

```bash
npm install
npm run dev
```

Abre la composición `PuckleVertical` en Remotion Studio para previsualizar el vídeo.

## Exportar a MP4

Desde esta carpeta, ejecuta:

```bash
npx remotion render src/index.ts PuckleVertical out/defence-gun-vertical.mp4
```

El vídeo exportado se guarda en `out/defence-gun-vertical.mp4`.
