# Vídeo vertical: Defence Gun de James Puckle

Composición Remotion vertical (9:16, 1080 × 1920) sincronizada con la narración AAC de aproximadamente 59 segundos.

## Vista previa

```bash
npm install
npm run dev
```

Abre `PuckleVertical` en Remotion Studio.

## Exportar a MP4

```bash
npx remotion render src/index.ts PuckleVertical out/defence-gun-vertical.mp4
```

El archivo de narración de origen está en `../docs/Audio.aac`; su copia para Remotion está en `public/Audio.aac`. La ilustración SVG utilizada en el vídeo también se conserva en `public/`.

El vídeo presenta la patente en un contexto histórico y educativo. El esquema y la animación son conceptuales, no reconstrucciones exactas ni planos de fabricación.
